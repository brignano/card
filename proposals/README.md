each starting with a `Status:` line and the issue that tracks it. Every proposal
has an issue; this file is the index, updated by any PR that adds a proposal or
changes its status. The shape is the fleet standard's
([brignano/ai-tools `fleet/README.md`](https://github.com/brignano/ai-tools/blob/main/fleet/README.md), "Proposals").
