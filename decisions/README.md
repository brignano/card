# Decisions

The decision log for this repo: one ADR per file (`decisions/NNNN-slug.md`),
numbered from `0001` and never renumbered. An ADR is not edited after merge,
except to mark it superseded; a changed mind is a new ADR that names the one it
replaces. The shape is the fleet standard's
([brignano/ai-tools `fleet/README.md`](https://github.com/brignano/ai-tools/blob/main/fleet/README.md), "Decisions (ADRs)").
